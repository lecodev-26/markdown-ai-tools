> **The Problem:** ChatGPT and Claude return broken markdown tables. Copy-pasting to Notion, Obsidian or GitHub breaks formatting.

## 🚀 Why This Site? (The Real Use Case)

Most people don't use this AFTER ChatGPT. They use it BEFORE.

**Workflow: Prompt Builder for Claude & ChatGPT**

1.  You have a messy business idea: `quiero una web para mi barbería, corte 15€, barba 10€...`
2.  You paste it into **Markdown AI Tools** → It converts it to a clean `| Campo | Valor |` table
3.  You copy that perfect markdown table and paste it into Claude / ChatGPT
4.  Claude understands it 10x better and builds the perfect website on the first try.

**Markdown is the language AI understands best.** We make your prompts AI-ready.

### Before (AI fails)
```
quiero una web para mi barberia en Barcelona que se llama Old School Barber, corta pelo hombre 15 euros...
```

### After (AI loves it)
```markdown
| Campo | Valor |
|---|---|
| Negocio | Old School Barber |
| Servicio 1 | Corte pelo hombre - 15€ |
| Horario | Lunes a Sábado 10-20 |
| Instagram | @oldschoolbcn |
```

## ✨ All Tools

| Tool | Description | Use Case |
|---|---|---|
| **Text → Markdown Table** | Turn messy notes, emails, AI output into a table | Most popular. Fixes AI output |
| **CSV → Markdown Table** | Auto-detects `, ; tab pipe` and quotes. RFC-4180 | Excel / Sheets → Notion |
| **List → Markdown Table** | Bullet or numbered list → clean 2-column table | Todo lists, features |
| **Markdown Table → CSV** | Reverse conversion for Excel/Sheets | GitHub → Excel |
| **Markdown Cleaner & Formatter** | Fix missing pipes, broken separators, extra columns | The Claude / ChatGPT fixer |

All tools work **100% client-side**. No backend. No data stored. AdSense & Privacy compliant.

```bash
cd markdown-ai-tools
npm install
npm run dev
```

Open `http://localhost:3000`
